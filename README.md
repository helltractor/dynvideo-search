# dynvideo-search

当前版本：v0.0.1

一个用于 Bilibili UP 主动态页的 Tampermonkey 脚本，用于自动滚动加载动态内容，并提取带有“动态视频”标识的原创视频 BV 号与标题。

## 项目定位

- 适用场景：Bilibili 个人空间动态页抓取
- 目标：自动发现并提取“动态视频”内容
- 输出：JSON 数组，包含 `bv` 和 `title`
- 使用方式：浏览器脚本 + Tampermonkey

## 项目结构

```text
dynvideo-search/
├── README.md
├── CHANGELOG.md
├── main.js
└── docs/                  # 可选：后续扩展说明文档
```

## 功能特性

- 自动滚动加载动态内容
- 过滤转发动态，只保留原创视频
- 检测“动态视频” badge
- 去重处理，避免重复 BV 号
- 启动 / 暂停 / 继续控制
- 实时展示当前已提取结果
- 导出 JSON 并支持复制到剪贴板

## 安装方式

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开本项目中的 `main.js`
3. 复制全部代码到新建的用户脚本中
4. 打开 Bilibili 空间动态页
5. 点击右下角浮窗中的“启动”按钮

## 常见问题

### 1. 浮窗没有出现
检查当前页面是否为用户空间动态页，确保 URL 包含 `https://space.bilibili.com` 并且页面已加载完成。

### 2. 没有提取到动态视频
确认当前 Up 主动态中确实存在带“动态视频”标识的内容，并适当增加滚动等待时间。

### 3. 是否有风控风险
脚本仅读取页面 DOM，不执行自动登录或非法请求，风险较低。
